# UI art in 8 requests (one image each)

Each request makes one image with several pieces on a green background. Send me the image and I cut it into the separate files. Attach the mockup to every request.

## Request 1: big plates
```
Attached is my game UI mockup. Make ONE image, 3:2 landscape, flat pure #00FF00 green background. Draw 3 separate empty game button plates stacked top to bottom, with wide green gaps between them, none touching:
1) charcoal plate, about 3 to 1 wide: square left end with small notched corners, pointed chevron right end.
2) the same plate with a deep crimson fill and small gold corner brackets top-right and bottom-left.
3) a longer crimson plate, about 4.7 to 1: pointed chevron LEFT end, square right end with notched corners.
Style for all: exactly like the mockup's frames, ornate beveled polished gold rim, thin inner gold hairline, subtle texture in the fill, imperial Roman / Red Rising look. Flat front-on, no perspective. Ornaments only at the ends and corners; the long top and bottom edges plain and even so they can stretch. NO text, NO icons, no shadow or glow outside the frames. Light from the top left.
```
