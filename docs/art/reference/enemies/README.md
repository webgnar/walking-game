# Enemy references

ChatGPT reference images for modeling the enemies that are still blocky (Tripo AI or Blender). They use the same style as the mangy wolf (`../mangy-wolf.webp`) and the Frazetta set: realistic painted creatures with matted fur, amber eyes and a warm rim light. Each one is a full-body side view facing left, standing on all four legs with the legs apart, on a plain light-gray background.
