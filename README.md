# The Ascent

An iPhone-first walking game: real steps become Soles, Soles build a hero and a base, and turn-based Trials test how you play. Design: [docs/game-design-document.md](docs/game-design-document.md). What the current build contains: [docs/mvp-notes.md](docs/mvp-notes.md).

Web build (Three.js + Vite), hosted on Vercel for phone testing. Play in landscape.

```
npm install
npm run dev
npm test
```
